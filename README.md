# Mission Tracker

A lightweight campaign tracker using stable OpenRAC hooks.

It shows:
- A planet-level objective after a level load
- Newly unlocked destinations
- Item/progress acquisition events

The first release intentionally avoids hardcoded mission-memory addresses. Richer per-mission text can be added when OpenRAC exposes a stable mission API.

Built for OpenRAC RAC1 PAL/NTSC-U. AI-assisted implementation. GPL-3.0-or-later.
